# GitHub Pages publishing package

Upload all files in this folder to the root of a GitHub repository, then enable GitHub Pages from the main branch and / (root).

The video stays in Tencent COS and is loaded from:

https://zhumei-surprise-2026-1465170147.cos.ap-nanjing.myqcloud.com/assets/handmade-gift.mp4

Before testing, configure COS CORS to allow your GitHub Pages origin, for example https://YOUR-USERNAME.github.io, with methods GET, HEAD and allowed headers *.
